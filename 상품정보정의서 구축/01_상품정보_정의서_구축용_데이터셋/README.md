# 상품정보 정의서 구축용 데이터셋

- `01_수집_데이터셋_1247건/collected_all.json`: 중복 제거 및 유효성 기준을 적용한 수집 자료 1,247건. 11번가 387, G마켓 347, 옥션 513건.
- `02_수집_스크립트_및_사용방법/`: 수집·보충·현황 확인·균형표집 코드, 카테고리 설정과 수집 회차별 원본. 실행 순서는 내부 README 참고.
- `03_균형표집_데이터셋_1000건/kitchen_100each.json`: 10개 상품군에서 각 100건. 11번가 341, G마켓 327, 옥션 332건.

수집 자료의 유효 기준은 가격 또는 상세이미지 주소 중 하나 이상이 있는 것이다. 모든 상세정보가 완전하다는 뜻은 아니다. 플랫폼 내 상품 ID를 기준으로 중복을 확인한다.

균형표집은 상품군별 플랫폼 비율을 가능한 한 균등하게 배분한다. 코드상 무작위 추출이 아니라, 플랫폼별 가용량에 따라 할당하고 읽은 순서에서 선택한다. 새로 수집하면 과거 1,000건과 같은 상품이 선택된다는 보장은 없다.

원본 파일은 수정하지 않았다. 복사 경로와 SHA-256은 `복사_출처.json`에서 확인할 수 있다.
