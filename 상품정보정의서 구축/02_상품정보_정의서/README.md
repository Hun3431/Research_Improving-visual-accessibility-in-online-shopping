# 상품정보 정의서 자료

1. `01_OCR_데이터셋`: 자유 구조화에 입력한 1,000건의 이미지별 OCR과 수집 메타데이터가 포함된 OCR 원본입니다. 두 자료는 상품 ID 1,000개가 같으며, 공백을 제외한 상품별 OCR 전체 문자열도 모두 같습니다.
2. `02_구조화_데이터셋`: 정의서 항목을 미리 넣지 않은 자유 구조화 결과 1,000건과 실제 프롬프트입니다. 결과에는 상품정보·거래정보·미분류 및 근거가 포함됩니다.
3. `03_동의어_정규화_데이터셋`: 동일 1,000건의 항목명 정규화 결과, 동의어 매핑표, 빈도 및 요약입니다.
4. `04_상품정보_정의서`: 상품정보 정의서와 도출 기록입니다. 정의서의 파일명과 문서 제목·JSON name을 정리했으며 나머지 원문 내용과 버전 메타데이터는 보존했습니다.

세 데이터셋은 상품 ID 집합이 완전히 일치합니다. 각 상품군은 100건씩입니다. 출처와 원본·복사본 SHA256은 `복사_출처_SHA256.json`에 기록했습니다.

도출 기록의 공통 기준은 전체 20% 이상이면서 10개 상품군 중 8개 이상에서 10% 이상입니다. 이는 현재 연구 프로젝트의 확정 기록(`output/study-procedure/definition-v5-confirmed.md`)과 일치합니다. 이번 정리는 기존 결과의 복사이며 정의서 항목을 새로 재계산하지 않았습니다. 근거 원문 일치율은 자동 문자열 대조 결과이며 사람 검수 정확도와 같지 않습니다.
