# 상품정보 정의서 — 주방용품

상품 상세페이지 텍스트에서 아래 항목을 뽑아 채우기 위한 정의서다. 상품군을 확인하고, 그 상품군에 적용되는 항목을 순서대로 채운다.

## 채우는 규칙

1. 상품군에 적용되는 항목만, 아래 목록 순서대로 모두 채운다.
2. 원문(상세페이지 OCR 텍스트)에 적힌 내용만 쓴다. 추정하거나 일반 상식으로 채우지 않는다.
3. 원문의 항목명이 달라도 뜻이 같으면 해당 항목에 넣는다. 항목별 "원문 이름"을 참고한다.
4. 원문에 없으면 값은 "정보 없음"으로 적는다. 항목을 빼지 않는다.
5. 한 정보는 한 항목에만 넣는다. 항목별 "구분 기준"을 따른다.
6. 옵션·구성마다 값이 다르면 모두 나열한다. 숫자와 단위는 원문 그대로 쓴다.
7. 불가·금지·권장하지 않음도 값이다. 가능 여부 항목에는 가능과 불가를 모두 적는다.
8. 어느 항목에도 해당하지 않는 정보는 채우지 않는다.

- **공통 (순서대로)** 사용 시 주의사항, 세척 방법, 열원·기기 사용 가능 여부, 색상, 식기세척기 사용 여부, 인증, 중량

## 기본 항목

### 품명 및 모델명

- **뜻** 상품의 이름과 제조사가 부여한 모델 코드.
- **값 형식** 이름 / 모델코드. 둘 중 하나만 있으면 그것만 적는다.
- **원문 이름** 품명, 제품명, 상품명, 모델명, 모델번호, 품번
- **구분 기준** 홍보 문구·상세페이지 제목의 수식어는 넣지 않는다. 브랜드명만 있으면 제품명이 아니다.
- **예시** `휴대용 수저세트` / `벨리나 IH 프라이팬/냄비` / `SW-BP2540`

### 재질

- **뜻** 상품을 이루는 소재. 부위별로 다르면 부위마다 적는다.
- **값 형식** 소재명. 부위가 여럿이면 `부위: 소재` 로 나열
- **원문 이름** 재질, 소재, 원재료, 몸체/뚜껑/손잡이 등 부위별 재질
- **구분 기준** 코팅이 적용 항목인 상품군에서는 코팅 종류를 코팅에 적는다.
- **예시** `알루미늄` / `스테인레스 스틸`

### 구성품

- **뜻** 포장에 함께 들어 있는 물품과 수량.
- **값 형식** 품목 + 수량 (예: 본품 1P, 뚜껑 1P)
- **원문 이름** 구성, 구성품, 세트 구성, 포함 내역
- **구분 기준** 색상·사이즈 옵션 선택지는 구성품이 아니다.
- **예시** `오징어게임 모양틀 3종과 별, 하트 5종 구성` / `도마 3ea, 걸이형스텐드 1ea` / `유리본체(800ml), 스텐 거름망, 스텐뚜껑`

### 크기

- **뜻** 상품의 치수. 옵션·구성품마다 다르면 전부 나열한다.
- **값 형식** 수치 + 단위(mm/cm). 가로×세로×높이 또는 지름·높이
- **원문 이름** 크기, 사이즈, 규격, 치수, 지름, 높이, 길이, 가로×세로
- **구분 기준** 무게는 중량, 담는 양은 용량에 적는다. 두께·날 길이가 적용 항목인 상품군에서는 그 값을 해당 항목에 적는다.
- **예시** `길이 260mm X 지름 90mm` / `지름 65mm * 230mm`

### 동일 모델의 출시년월

- **뜻** 같은 모델이 처음 출시된 연월.
- **값 형식** YYYY.MM
- **원문 이름** 출시년월, 출시일, 제조년월(동일 모델 출시 의미일 때)
- **구분 기준** "별도 표기", "상세페이지 참조"는 값이 아니다 → 정보 없음.
- **예시** `2014.09` / `2025.11`

### 제조자 및 수입자

- **뜻** 만든 회사와, 수입품이면 국내로 들여온 회사.
- **값 형식** 회사명. 둘 다 있으면 `제조사 / 수입원`
- **원문 이름** 제조자, 제조사, 제조원, 수입자, 수입원, 수입판매원
- **구분 기준** 판매원·유통사·쇼핑몰명은 넣지 않는다.
- **예시** `신성실리콘` / `인터앤씨` / `(주)Tree`

### 제조국

- **뜻** 상품이 만들어진 나라. 회사 이름이 아니라 국가다.
- **값 형식** 국가명 (예: 대한민국, 중국)
- **원문 이름** 제조국, 원산지, 생산국, Made in
- **구분 기준** 회사명은 제조자 및 수입자에 적는다. "중국 OEM"처럼 원문 표기는 유지한다.
- **예시** `대한민국` / `중국(OEM)`

### 수입신고 문구

- **뜻** 수입 기구·용기인 경우에만 적는 법정 문구.
- **값 형식** "식품위생법에 따른 수입신고를 필함". 국산이면 해당 없음
- **원문 이름** 수입신고, 식품위생법에 따른 수입신고 필
- **구분 기준** 국산이거나 문구가 없으면 정보 없음.
- **예시** `식품위생법에 따른 수입신고를 필함` / `수입식품안전관리특별법에 따른 수입신고를 필함`

### 품질보증기준

- **뜻** 보증 기간이나 적용되는 분쟁해결 기준.
- **값 형식** 기간(예: 구입일로부터 1년) 또는 기준 문구
- **원문 이름** 품질보증기준, 품질보증기간, 보증기간, 소비자분쟁해결기준
- **구분 기준** 인증·시험성적은 인증에 적는다. 교환·반품 기간은 넣지 않는다.
- **예시** `관련법 및 소비자 분쟁해결 규정에 따름` / `공정거래위원회에서 고시한 소비자 분쟁해결 기준에 따름`

### A/S 책임자와 전화번호

- **뜻** 고장·문의를 받는 곳의 연락처.
- **값 형식** 전화번호. 카카오톡 ID·이메일만 있으면 충족하지 않는다
- **원문 이름** A/S 책임자, 고객센터, 소비자상담실, 고객상담 전화
- **구분 기준** 전화번호가 없고 카카오톡 ID·이메일만 있으면 정보 없음.
- **예시** `053-856-2468` / `010-5301-0458` / `070-5133-4629`

## 공통 항목

### 사용 시 주의사항

- **뜻** 사용자의 안전이나 제품 파손과 관련된 경고 (화상·파손·변형·과열 등). 배송·교환·반품 안내는 넣지 않는다.
- **값 형식** 주의 문장 나열. 원문 표현 유지
- **원문 이름** 주의사항, 사용상 주의사항, 사용 전 주의사항, 취급 주의, 경고
- **구분 기준** 세척은 세척 방법, 보관은 보관 방법, 열원·기기 가능 여부는 열원·기기 사용 가능 여부, 식기세척기는 식기세척기 사용 여부에 적는다. 배송·교환·반품 안내는 넣지 않는다.
- **예시** `구입 후 세척하고 사용하십시오.` / `직화나 화기 근처에 가까이하지 마십시오.` / `강한 충격은 제품의 손상을 가져올 수 있으므로 주의하십시오.`

### 세척 방법

- **뜻** 세척·건조 요령과 쓰면 안 되는 세제·도구.
- **값 형식** 권장: … / 금지: … 로 나누어 적는다. 한쪽만 있으면 그것만
- **원문 이름** 세척 방법, 세척 및 관리 방법, 세척 시 주의사항, 손질 방법
- **구분 기준** 식기세척기는 식기세척기 사용 여부에 적는다. 열탕소독·보관 방법이 적용 항목인 상품군에서는 그 내용을 해당 항목에 적는다.
- **예시** `부드러운 스펀지로 닦아주세요. 거칠거나 금속성의 수세미를 사용하면 제품이 손상될 수 있습니다.` / `철수세미나 금속 조리기구 등의 사용을 가급적 피하고 부드러운 스펀지로 세척` / `칼자국이 심할 경우 거친사포, 고운사포 순으로 샌딩 후 도마 전용 미네랄오일 도포`

### 열원·기기 사용 가능 여부

- **뜻** 가열 기구와 조리 가전에서 쓸 수 있는지. 대상: 가스레인지, 인덕션, 하이라이트, 전기레인지, 핫플레이트, 직화, 전자레인지, 오븐, 에어프라이어, 식기소독기. 원문에 언급된 기구만 적는다.
- **값 형식** 기구명: 가능 / 불가 / 조건부(조건) 을 쉼표로 나열 (예: 가스레인지: 가능, 인덕션: 불가)
- **원문 이름** 사용가능열원, 사용불가열원, 전자레인지/오븐/에어프라이어 사용 여부, 사용 가능 기기
- **구분 기준** 식기세척기·냉동실·열탕소독은 여기에 넣지 않는다 (각각 별도 항목).
- **예시** `가스레인지: 가능, 전기레인지: 가능, 전자레인지: 불가, 오븐: 불가` / `가스레인지: 불가, 직화: 불가, 전자레인지: 가능, 오븐: 가능` / `가스레인지: 불가, 전기레인지: 불가, 직화: 불가, 전자레인지: 가능, 오븐: 가능`

### 색상

- **뜻** 선택 가능한 색. 옵션이 여럿이면 모두 나열한다.
- **값 형식** 색 이름을 쉼표로 나열
- **원문 이름** 색상, 컬러, 색상 옵션
- **구분 기준** 코팅·마감 방식은 색상이 아니다.
- **예시** `그레이` / `화이트` / `프리미엄 레드, 머스타드, 로얄그린, 다크블루, 그레이`

### 식기세척기 사용 여부

- **뜻** 식기세척기에 넣어 세척할 수 있는지.
- **값 형식** 가능 / 불가 / 조건부(조건)
- **원문 이름** 식기세척기 사용 여부, 식기세척기 사용 가능, 식세기
- **구분 기준** 일반 세척 방법은 세척 방법에 적는다. 전용 세제 등 조건은 괄호로 함께 적는다.
- **예시** `사용가능` / `사용 불가` / `권장하지 않음`

### 인증

- **뜻** 받은 인증·시험성적. 품질보증기준과 다른 항목이다.
- **값 형식** 인증명 (예: KC 국가통합인증마크, KCL 항균시험)
- **원문 이름** 인증, KC 인증, 안전인증번호, 시험성적, 특허, 항균 시험
- **구분 기준** 유해물질 불검출이 적용 항목인 상품군에서는 불검출 표기를 그쪽에 적는다. 품질보증 기간은 품질보증기준에 적는다.
- **예시** `FDA / RoHS 기준 통과` / `NSF(National sanitation Faoundation,미국위생재단) 인증` / `NSF 인증, FSC 인증`

### 중량

- **뜻** 상품 무게. 구성품마다 다르면 각각 적는다.
- **값 형식** 수치 + 단위(g/kg)
- **원문 이름** 중량, 무게, 제품 무게
- **구분 기준** 담는 양(ml/L)은 용량이다.
- **예시** `345g (식소다 63g 포함)` / `163g` / `271g`

## 특화 항목

### 용량

- **적용 상품군** 냄비, 밀폐용기, 식기/그릇, 조리도구, 주전자/티포트, 텀블러/보온병
- **뜻** 담을 수 있는 양.
- **값 형식** 수치 + 단위(ml/L). 옵션마다 다르면 모두
- **원문 이름** 용량, 옵션별 용량, 최대 용량
- **구분 기준** 배터리 용량 등 담는 양이 아닌 것은 넣지 않는다.
- **예시** `500ml` / `1.8L` / `600ml`

### 보관 방법
